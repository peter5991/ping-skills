# 手感参数表(motion tokens)

> 动效参数不凭空写数字,从本表取值。来源:9 站实测惯例 + 项目既有配方(ENGINEER_PROMPT R 系)对齐。
> 原则:**入场一次性、ease-out 主基调、spring 只给小件微交互**。

## 缓动曲线

| 名称 | 值 | 用途 |
|---|---|---|
| ease-out-expo(主基调) | `cubic-bezier(.22,1,.36,1)` | 一切入场、reveal、stagger;GSAP 对应 `expo.out` |
| ease-out-power | `cubic-bezier(.33,1,.68,1)` | 微交互、hover;GSAP `power3.out` |
| spring(小件限定) | `cubic-bezier(.34,1.56,.64,1)` | logo/标签/卡片 hover 弹出(pacomepertant `--ease-spring`);**入场编排与滚动叙事禁用** |
| linear | `linear` | 仅 scrub 映射(滚动进度直接驱动),滚动本身就是一种缓动 |

禁:bounce/elastic 类夸张回弹(课堂与展示页同规);CSS 自带 `ease-in-out` 做入场(先加速显得迟疑)。

## 时长

| 场景 | 区间 | 备注 |
|---|---|---|
| hover/微交互 | .2s ~ .35s | 超过 .4s 就显得"肉" |
| 元素入场(单件) | .5s ~ .6s | rise/reveal 标准值 |
| 大容器/幕布揭示 | .8s ~ 1s | clip-path 幕布、色块转场 |
| 主标题 scramble | ~1.2s | 一页一处 |
| 页面转场 | ≤ .8s | 超过就是让人等 |
| 数字滚动 | 1.2s | ease-out 减速到位 |

## stagger 间隔

| 规模 | 间隔 | 出处 |
|---|---|---|
| 2~5 件 | .12s | R2 逐行揭示同级 |
| 6~12 件 | .05s ~ .08s,第 6 件起封顶 .5s 总延迟 | 项目 R1 实测值 |
| 逐字(中文) | 40ms ~ 80ms/字,单字点亮 120ms | 项目 R9 实测值 |

## lerp 阻尼系数

| 用途 | 系数 | 备注 |
|---|---|---|
| 平滑滚动(Lenis) | .1 | Lenis 默认,9 站通行值 |
| 自定义光标 | .15 ~ .2 | 跟手但不瞬移 |
| 图片跟随预览 | .08 ~ .12 | 比光标更"拖"一点才有贵感 |
| 视差映射 | — | 不用 lerp,直接 `scrollY × 系数`(系数 ≤ .5) |
| 截止阈值 | 差值 < .1px 吸附目标值 | 防永远微调 |

### 帧率无关(motion-web 并入)

- **每帧系数写法在 30/60/120fps 是三个不同滤波器**。帧率无关版:`x += (t - x) * (1 - exp(-k·dt))`,k 单位 1/s。实测 k:相机跟随 4.5、回正 2.2、氛围自水平 0.35(低 k 是合法设计,3 秒才稳)。
- **稳态滞后是算术**:追动目标时恒差 `speed/k`,不是调参失败。修复用提前项 `aim = target + targetVel / k`,不要加硬弹簧(会杀掉柔软度)。
- **一量一滤波一目标**:多个修正叠进同一滤波器会互相拉回(实测振荡 ±0.15~0.45/帧);修正项各自滤波后并入目标,升/降可用非对称 k(18 / 2.2)。
- **欠阻尼弹簧替代 lerp**:`vel += (t-x)·STIFFNESS·dt; vel *= DAMPING`,STIFFNESS 60~90,DAMPING = 0.86 弹跳 / 0.90 果冻 / 0.93 沉稳。lerp 单调减速读作"滑",过冲沉降才读作"落地有重量"。
- CSS 无库弹簧:`linear(0, 0.32 8%, 1.03 30%, 1)` 采样点曲线;原生 stagger 可用 `sibling-index()`。小件不引库也能有弹簧手感。
- **滚轮惯性护栏**(滚动叙事页):~90px 阈值触发一步 + 550~650ms 锁定 + 每帧 acc×0.92 衰减——触控板抬手后还喷 ~1s 惯性事件,裸累加必鬼触。

## 遮罩 reveal 参数

- 内层初始位移:`translateY(105%)`(逐行)/ `translateY(110%)`(逐词,略多防字重溢出)
- 逐行 delay:.12s 递增,总行数 ≤ 5(超过分批或改 stagger)
- 预加载器数字滚动:整数百分比,`translate3d(0, N%, 0)` 遮罩上滚(camille 式)

## 循环氛围(背景层限定)

- 呼吸/漂浮:振幅 ≤ 8px,周期 ≥ 4s,只动 transform/opacity
- 粒子:Canvas 2D 数百个以内;`document.hidden` 停 tick
- 一页持续动效 ≤ 2 处
