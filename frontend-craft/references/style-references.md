# 风格解码库(style references)

> 整条风格线的解码档案:配色 token、排版规则、布局纪律、签名视觉、组件规则 + 实战适配记录。
> 与 techniques.md(单手法)互补:这里管"一整套风格怎么成套复刻/适配"。
> 每条目:来源链接 → 解码规格 → 适配红线(哪些能抄、哪些必须换)。

## 参考网页解码协议(拿到链接后按此执行)

用户给出参考网页时,分两层分析,缺一不可:

1. **视觉规格层**(看到什么):配色 token(具体色值+用途纪律)、字族/字重/字号阶梯、布局骨架与间距、签名视觉、组件样式。WebFetch/截图拿不到色值时读 computed style 或样式表。
2. **实现方式层**(怎么做的):抓页面源码,识别——
   - **库指纹**:script src、全局变量(`gsap`/`THREE`/`Lenis`/`__NEXT_DATA__` 等)、构建器特征(Vite/Next/ bundler 注释),判断技术栈与主控库;
   - **动画 driver**:哪些效果是 CSS(transition/keyframes)、哪些是 rAF/Canvas/WebGL、滚动驱动归谁管——对应到 techniques.md 的 T 级,判断复刻成本;
   - **DOM 结构手法**:遮罩 reveal 的容器拆法、canvas 层叠顺序、data 属性范式;
   - **资产**:字体文件(许可!)、图片/视频/模型来源与体积。
3. **输出**:按本库条目格式写解码规格 + 复刻/适配建议(能 T0 不 T1);落地后回写本库。

**红线**:解码 ≠ 连锅端。品牌签名元素(Logo、标志性图形组合、独创插画)必须替换为站点自有主题(见各条目"适配红线");商业字体不可自托管,用 libs.md 字体节的平替。

## Dala — 暗色虚空极简 + 生成式粒子(dark-void minimalism)

- **来源**:refero.design 风格页 `https://styles.refero.design/style/e5f5f8cf-e68d-4ed1-bbf5-6b67569af648`(原站 dala.craftedbygc.com);官方气质 "constellation floating on black velvet"。同族:Linear / Vercel / Anthropic 的"黑色作为主动设计材料"。
- **收录**:2026-09-23,已实战落地于 peter5991.github.io(学者个人主页,MOF 晶格适配版)。

### 配色(7 色,纯黑即设计本体)

| 色 | 值 | 用途纪律 |
|---|---|---|
| Void | `#000000` | 唯一页面背景,**不用深灰** |
| Bone | `#ffffff` | 标题、正文、导航激活态 |
| Ash | `#9a9a9a` | 次要导航、幽灵链接 |
| Mist | `#bdbdbd` | 三级正文、说明文字 |
| Iris | `#8052ff` | 品牌紫——**只做按钮/Logo/强调,每屏一个紫色元素**;不做大面积背景,不加阴影边框 |
| Saffron | `#ffb829` | 琥珀高亮——只做小标签/眉线/角色标注 |
| Verdant | `#15846e` | 渐变端点、粒子氛围色 |

紫×黄冷暖对比是品牌张力;两强调色分工明确(紫=动作,黄=标注),不算违反"单主色"——黄从不出现在可交互元素上。

### 排版(靠尺度不靠字重)

- 单一字族 PPNeueMontreal(**商业字体,不可直接自托管**;平替见 libs.md 字体节:Inter 可变字重 100–900)。
- 113px 展示标题与 15px 正文**同用 weight 400**;42px 以上加 `-0.04em` 负字距;标题禁粗体。
- 招牌细节:**18px 正文用 weight 200 超细体**,段落轻盈不具攻击性。
- 导航:13–14px / 600 / 大写 / 0.025em。字号阶梯 Minor Third(1.2)。

### 布局("虚空即设计")

- 内容宽 1280px,区块间距 60–120px,极疏朗。
- 两栏非对称锯齿节奏(左标题右视觉,交替翻转)。
- **无卡片、无边框、无阴影、无分割线**——靠留白分组;透明顶栏,无模糊背景。

### 签名视觉与组件

- **粒子星座主视觉**:数千个彩色描边小三角形(非圆点)组成有机形状 + 全屏低透明度环境粒子;粒子即品牌,Hero 区禁摄影/插画/截图。
- 组件:紫色胶囊按钮(圆角 22.5px、大写 14px)、幽灵文字链接、无容器人物卡、8px 轮播圆点、琥珀眉线 + 超大左对齐标题 + 超细正文的三件套 section 头。

### 适配红线(实战教训)

1. **三角形粒子"大脑"是它的品牌签名,不可照搬**——换组织逻辑保留粒子语言:学者页用 MOF pcu 晶格(节点=金属簇三角形、棱中点=连接子微点、预计算拓扑边),企业页可用网络/地形/轨道等自有主题。
2. 紫黄双色可直接沿用(通用色);但 Logo 渐变三角图标是品牌资产,须重绘。
3. CJK 场景:200 超细体只对西文成立,中文走系统栈、靠字重对比(design-foundation CJK 反规则)。
4. 落地实现见 techniques.md T0-13;本风格可以做到**整站零第三方库**。
