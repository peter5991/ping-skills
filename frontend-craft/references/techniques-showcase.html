T0-12 / DECLARATIVE
声明式动效属性(siena 范式)

本页所有 reveal/parallax/cursor 都由 data-* 属性 + 一个 init 函数驱动——动效系统与内容解耦,页面即配置。这几段文字本身就是 data-reveal 进场的。

<div data-reveal>滚动入视口淡入</div>
<div data-parallax="0.28">差速滚动</div>
<div data-cursor="VIEW">光标态切换</div>

// 一个 init 统一扫描接管(本页实际运行版):
document.querySelectorAll('[data-reveal]').forEach(el => io.observe(el));
document.querySelectorAll('[data-parallax]').forEach(el => px.push(el));
document.querySelectorAll('[data-cursor]').forEach(el => bindCursor(el));

T1/T2 手法(Lenis 惯性滚动、ScrollTrigger pin、粒子背景、图片扭曲 shader)不进本页——它们需要库与降级策略,见 techniques.md 对应条目与"能低不高"分级原则。
