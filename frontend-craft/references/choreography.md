# 编排纪律(choreography)

> 来源:motion-web references 蒸馏(2026-09-22)。管"多个动效如何排布在同一时间轴上";单个动效的参数查 motion-tokens.md。
> 适用:滚动叙事、多元素入场编排、转场序列。单元素微交互不用看本文件。

## 时间轴

1. **缓动只存在一层**。驱动时间轴本身保持线性,缓动加在最末端;两层缓动相乘 = 中段平方、两端拍扁,反而更硬切。
2. **一窗口一事件**。淡入会吃掉同窗口内一切其他运动——fade-in 只占段落开头 ~10%,其余时间让给真正要看的东西;三件事 = 三个相邻时间窗,不叠窗。
3. **速度归零的关键帧后必有死拍**(smoothstep 段首 22ms 只走 7cm):要么另一条轨填拍,要么检查是不是某轨时间戳写错了。
4. **money frame**:每幕欠一帧"画面完成 + 文案完成 + 可交互"同时成立的静帧;动了 dwell 时长必须同一次编辑重算交互窗口。
5. **静止率是"灵动 vs 飘"的判据**:公认灵动的参考件 51% 相邻帧近同,飘版只有 13%。缓动改不了静止率;有效旋钮是 drawing clock(量化到 ~15 states/s,只用于表演层,不用于相机/跟随)。

## 编排检查单

- [ ] 同一时间窗内有几个动效在抢注意力?(>1 → 拆窗)
- [ ] 每幕的 money frame 截得出来吗?(截不出 → 编排没收敛)
- [ ] 相邻帧静止率测过吗?(全在动 = 飘;量化 drawing clock)
- [ ] 转场能冻结在任意时刻 t 检查吗?(不能 = 没法验收,见 SKILL.md 验收清单)
