# 静帧层规范 — 布局 / 排版 / 配色

> 动效全关截图也要成立。本文件管"不动"的部分;动效选型见 techniques.md,参数见 motion-tokens.md。
> 与项目 hallmark(反 AI 味)同源,此处为通用网页版;课堂课件另有专案纪律(lesson-prep),以专案为准。

## 配色

1. **单主色调**。一个主色承担所有强调(链接、按钮、高亮、图表第一色);深色底向主色**微微偏移**(不纯黑),浅色底向主色微偏暖/冷。
2. 层次靠**明度阶梯**不靠多色:底色 / 表面色(卡片)/ 边框 1px 细线 / 正文 / 次要文字(.6 透明度)五级封顶。
3. 禁:紫蓝/紫粉渐变背景、渐变色标题文字、极光色块、漂浮圆球、彩色发光阴影。
4. 成列数字加 `font-variant-numeric: tabular-nums`。
5. 深色页固定 UI 优先 `mix-blend-mode: difference`(techniques T0-4)而不是写死颜色。

## 排版

1. **超大字 + 大留白是九站共通骨架**:hero 标题字号可达 10vw+;宁可字大留白多,不要字小塞满。
2. 中文只用系统栈(`"Microsoft YaHei","PingFang SC",system-ui`),靠**字重与字号**拉开层级,不靠斜体/花体;西文展示页可用一款展示字体搭配(本地化 woff2),全页字体 ≤ 2 款。
3. 层级对比要"悬殊":标题:正文 ≥ 3:1;温吞的 1.5 倍差是 AI 味来源之一。
4. 标题不用斜体、不用渐变填充、不用文字描边特效。

## 布局骨架(按内容选型,禁止套娃)

| 内容类型 | 骨架 |
|---|---|
| 流程/步骤 | 纵向时间线、分步叙事 |
| 对比 | 左右分栏(可不对称 6:4) |
| 数据 | 大数字先行,图表随后 |
| 清单/特性 | 不对称网格(大小卡片混排,非等宽三列) |
| 作品/案例 | 列表 + hover 预览(T0-9)或大图错位排 |

纪律:
- **布局偏向一侧**(宽左边距或反之),不要所有元素居中;"居中标题 + 三列等宽卡片 + 底部署名"是禁用模板。
- 同站点/同课程相邻页面**骨架必须不同**。
- 分隔用 1px 细线,不用厚重单侧色条;没有语义的装饰一律删掉。
- emoji 不当功能图标;不编造数据与数字——页面上每个数字有出处。

## 反 AI 味快检(交付前自答)

1. 这页的主色有几个?(>1 个强调色 → 砍)
2. 有没有渐变标题/紫蓝渐变背景/发光卡片?(有 → 删)
3. 骨架和上一页一样吗?(一样 → 换)
4. 数字都有出处吗?(编的 → 删)
5. 装饰元素能说出语义吗?(说不出 → 删)
6. 标题和正文的字号差够悬殊吗?(温吞 → 拉大)
7. 全卡片统一 `translateY(-4px)` hover?全页统一 fade-up 入场?一套缓动走天下?(有 → 换花样,这是动效层的 AI 味)

## 实测基准(motion-web 并入,2026-09-22)

1. **类型跳变**:获奖站 display÷body ≈ 8×(范围 3.3~14×),body 12~16px,display 52~218px;没有站落在"全在 16~48px"温吞区间。"没设计感"先量这个比。
2. **measure 逐元素定**:15/15 获奖站无全局 max-width;正文行长 60~75ch,标题区另算。
3. **CJK 展示字反规则**(西文那套别照搬):行高要更大(display 也 1.4~1.6)、禁负字距(闭字面会糊成块)、字重对比优于字号对比。
4. **先选方言再保持一致**(实测中位数):创意页 radius≈1 / box-shadow≈0 / 全出血 83%;产品页 radius≈8 / box-shadow≈17.5 / 全出血 32%。控件可以产品化,画布不许叛变——"像 AI 做的"多半是产品 canvas(nav+CTA+三卡片)套在创意页上。
5. **结构多样性底线**:每页 ≥3 种 section 骨架——这是比配色更被感知为"设计过"的变量。
6. **组件状态矩阵**:rest/hover/active/focus-visible/disabled/loading/error/empty/success 九态;用 `:focus-visible` 不用 `:focus`;hover 样式包进 `@media (hover:hover) and (pointer:fine)`。缺状态是"像原型"的首因。
7. **能点 ≠ 看得出能点**:邀请标记常驻(cursor 变化只能确认猜测,不能发起猜测);描边式标记(stroke-dashoffset)优于淡入(余光只追移动边缘);点击/拖拽同元素时按下记位置、抬手判定(6px 阈值),禁 pointerdown 直接开、禁长按当入口。
