# 三层金字塔 PPT 内容规划

核心信念：**观众离场只记得一句话。** 所有页都为这句话服务；任何不为它服务的页，删掉。

## 模型

```
      ▲ 塔尖：一句话核心主张（结论先行）
     ███ 塔身：3-4 个支撑论点（MECE，每论点 = 一个章节）
    █████ 塔基：逐页论据（数据/案例/对比，每页只讲一个点）
```

- **塔尖**：完整的一句话，包含"谁 + 做了什么 + 带来什么结果"。不是主题（"智能回收系统"），而是主张（"我们用视觉识别把校园回收准确率提到 92%"）。
- **塔身**：3-4 个论点，少了立不住，多了记不住。论点间必须 MECE（不重不漏）。
- **塔基**：每页 = 1 个结论式标题 + 证据素材 + 视觉形式 + 大字文案。

## 执行流程

### 第一步：收集原料（一轮问齐，不预设默认值）

必须拿到 4 项输入，缺一就问（可合并成一轮提问）：

1. **主题**：讲什么？一句话项目/议题背景
2. **受众**：谁在听？他们关心什么、担心什么？（不预设受众类型，必须问）
3. **规模**：页数上限或演讲时长
4. **素材**：已有内容、必须包含的信息、不能碰的红线

### 第二步：一次出全稿

按 `references/planning-guide.md` 的模板，一次性产出完整《PPT 内容规划书》初稿：

- 塔尖主张（给 2-3 个候选表述，标注推荐）
- 塔身论点 + 排序理由（时间线 / 结构并列 / 重要性递进，三选一，写明为什么）
- 逐页规划表：页码 | 章节 | 结论式标题 | 证据素材 | 视觉形式 | 大字文案
- **自检报告**（见下方清单，逐项给结论，不空喊"通过"）

### 第三步：批注迭代

用户批注后原地更新规划书（保持同一文档，版本号 +1 并注明改了什么），不重新发散。

## 写作规则

1. **标题必须结论式**："回收准确率提升至 92%"，不是"回收率情况介绍"。只读全部标题，就能复述整个论证。
2. **大字文案 ≤ 15 字**：是要烧进图里/做超大标题的那句；细节数字与解释进"证据素材"列，不进大字。
3. **每页只讲一个点**：一页想塞两个点就拆页；页数超上限时合并塔基，不动塔身。
4. **证据要具体**：优先毛边数据（92.3% 而非"约 90%"）、具体案例、前后对比；写"待补数据"占位也比写"效果很好"强。
5. **受众决定塔身**：技术评委要原理与验证，投资人要市场与回报，老师要过程与规范——塔身论点必须能从"受众关心什么"推出来。

## 自检清单（全稿必附，逐项给证据）

| 检查 | 方法 | 不通过的表现 |
|---|---|---|
| 必要性 | 逐个删掉塔身论点，塔尖是否失去支撑 | 某论点删了塔尖照样成立 → 该删 |
| 充分性 | 塔身论点拼起来能否逻辑推出塔尖 | 拼完还差一环 → 补论点 |
| MECE | 论点间有无内容重叠或明显遗漏 | 两论点证据素材高度重合 → 合并 |
| 故事线 | 只读逐页标题，能否复述完整论证 | 读下来是目录而非故事 → 重写标题 |
| 单点原则 | 每页是否只讲一件事 | 标题含"和/以及/同时" → 警惕拆页 |

## 项目专用约束（PPT 定制设计服务项目；其他场景可忽略本节）

1. **竞赛路演参考塔身**（按受众与页数裁剪，不机械套用）：痛点 → 方案 → 产品/技术 → 数据验证 → 商业模式 → 团队 → 愿景。
2. **页数默认 9-12 页**，对齐作品集套数；封面 + 塔尖结论页计入总页数。
3. **大字文案列直接喂生图 prompt**：遵守项目"大字少字"规则（生图只烧大字，小字正文后期叠加文本框），风格模板见项目 `prompts/` 目录。
4. **虚构内容仿真**：选题用竞赛高频方向，数据做毛边，每页证据素材附一句话背景。
