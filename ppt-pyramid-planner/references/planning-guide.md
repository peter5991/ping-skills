## 塔基：逐页规划

| 页码 | 章节 | 结论式标题 | 证据素材 | 视觉形式 | 大字文案（≤15 字） |

- 必要性：逐论点删除测试 → <结论与证据>

## 塔身常见结构模式

| 模式 | 适用 | 示例 |
|---|---|---|
| 问题→方案→验证→价值 | 路演、答辩、产品发布 | 痛点 / 方案 / 数据验证 / 商业前景 |
| 时间线 | 项目汇报、进度复盘 | 现状 / 已做 / 在做 / 计划 |
| 结构并列 | 方案介绍、组织介绍 | 技术 / 团队 / 资源 / 服务 |
| 重要性递进 | 争取资源、说服决策 | 成本 / 风险 / 战略意义 |
| 对比式 | 竞标、选型 | 现状方案 vs 我们方案（逐维度） |

选模式的标准：**受众听完最自然的复述顺序**。不要为显得高级而选不贴切的结构。

## 结论式标题写法

| 反例（主题式） | 正例（结论式） |
|---|---|
| 市场调研 | 73% 用户因分类麻烦放弃回收 |
| 产品介绍 | 3 秒完成识别，无需人工分拣 |
| 财务分析 | 单台设备 14 个月回本 |
| 团队介绍 | 核心成员含 2 项国赛金奖 |

检验方法：标题里有没有**数字、动作或判断**？三者皆无，大概率是主题式标题。

## MECE 速查

- **重叠测试**：两个论点能否用同一份证据支撑？能 → 合并。
- **遗漏测试**：受众最可能问的 3 个问题，是否各有论点接住？没有 → 补。
- **数量约束**：4 个论点还装不下，说明粒度太细，向上归并一层。

## 大字文案规则

- ≤ 15 字，读出来不超过 3 秒
- 优先句式：数字 + 结果（"92.3% 识别准确率"）、动作 + 对象（"让回收像扫码一样简单"）
- 一页只有一句大字；解释、来源、限定语全部放到证据素材列
