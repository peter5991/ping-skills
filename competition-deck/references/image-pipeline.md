# 配图管线(Codex CLI 生图)

deck 的配图(人物/场景/IP/装饰图形)由 Codex CLI 的 `image_gen__imagegen` 工具生成。**只产元素,不产页面;图内不产文字。**

## 调用命令(2026-09-19 实测通过)

```bash
codex exec --sandbox workspace-write "请调用 image_gen__imagegen 工具生成一张图片:<元素描述>。生成后用 view_image 确认效果,然后把图片文件保存到 <绝对路径>(若工具返回的是 URL 或 base64,请下载/解码保存)。最后报告保存路径与文件大小。"
```

- 单次约 3 万 token,单张 1~3 分钟;**串行调用,不并发**(token 与稳定性)。
- 产物 PNG 约 800KB/张;落盘 `decks/<项目名>/assets/<语义名>.png`,HTML 相对引用 `assets/xxx.png`。
- 生成后用 Read 工具亲自看图验收,不合格改提示词重生成——**不要不看就嵌进页面**。

## 统一母提示词(保证全套同风格)

每个元素描述前拼接母版段(按 deck 色板替换主色描述):

**场景/人物类**(摄影质感):
> 明亮真实摄影风格,色调清新,白色与浅<主色名>(如薄荷绿)为主环境色,画面通透高亮度,中国现代场景(高校/实验室/医院/园区),人物自然真实但面部弱化或远景虚化处理,专业商业摄影,16:9 构图预留裁切空间,画面中不出现任何文字、字幕、水印、logo。

**图标/装饰类**(扁平插画):
> 扁平矢量插画风格,圆润造型,纯白背景,主色 <主色 hex 或名称>,极简造型,适合作为 PPT 装饰图形,画面中不出现任何文字。

**IP 吉祥物**(全套只生成一次,各页复用):
> 扁平插画风格卡通吉祥物,<形象描述>,圆润可爱,纯白背景,品牌 IP 质感,不出现任何文字。

## 生图清单管理

阶段 1 页面清单确认时,同步产出**配图清单**:文件名 | 所在页 | 元素描述 | 类型(场景/图标/IP)。阶段 4 逐页制作时按清单调用,生成一张验收一张。

## 纪律

1. **图内零文字**:一切文字、数字、图表 HTML 原生渲染。生图模型写小字必乱码,且数字烧进图里不可改(违反真实性红线)。
2. **不伪造证据**:证书、检测报告、政策截图、专利文件一律用用户提供的真实件;没有就不放,换成文字说明。生图伪造证书 = 比赛一票否决级事故。
3. **真实照片优先**:团队活动、实验场景、调研现场优先让用户提供真实照片(bp-roadshow-guide:调研照片要本人出镜);生图只补缺口,且页面图注标「示意图」。
4. **人物面部弱化**:提示词固定带「面部弱化/远景虚化」,避免 AI 人脸特写穿帮。
5. **失败处理**:连续 2 次生成不满意,换描述维度(构图→色调→风格)再试;仍不行就用纯 CSS 图形替代该元素,不硬等。

## 体积与打包

10 张场景图约 8MB,可接受;如需压缩用 `npx sharp-cli` 或让用户过一遍压缩工具,**不为了体积改引用方式**(保持相对路径,目录整个打包带走)。
