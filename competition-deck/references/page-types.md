# 页型目录

从高水平竞赛 BP 路演 PPT 反拆的 10 种页型 + 3 种通用页型。每种页型给出:骨架结构 / 内容要点 / 动效映射(R/P 编号,全文见 electron/agent/pagegen-prompt.ts)/ 配图需求(生图元素清单,走 image-pipeline.md)。

**选型纪律**:相邻页不得同骨架;一套 deck 至少用 5 种页型;页型服务内容,内容塞不进页型就换页型,不要硬塞。

---

## 比赛模式页型

### T1 封面
- **骨架**:左 60% 信息区(赛事标识位 + 超大项目名 + 一句话定位 + 2×2 信息框:赛道/负责人/组别/联系方式),右 40% 主视觉图。
- **内容要点**:项目名是唯一主角,字号全套最大;一句话定位 ≤15 字,说清「做什么的」。
- **动效**:P1 逐字扰动(项目名,加载即播一次)或 R2 逐行揭示;信息框 R1 错峰。
- **配图**:主视觉 1 张(人物+场景或产品场景,风格定全套基调);IP 图标 1 个(全套复用)。

### T2 政策/背景场景
- **骨架**:顶部一条宽幅结论句(关键词橙色高亮)→ 中部 2 张政策/证据卡片(日期+名称+两行摘要)→ 底部横向时间轴串 3~4 个证据节点(截图卡片/来源标注)。
- **内容要点**:这一页卖的是「可信」——每条政策/证据必须真实可查,标注来源。
- **动效**:结论句 R9 逐字点亮;时间轴节点 R1 错峰。
- **配图**:可不要(纯信息页);若用截图,让用户提供真实截图,不生图伪造。

### T3 行业痛点
- **骨架**:3~4 列竖向痛点卡(图上文下),最后一张换强调色收口为「核心痛点」。
- **内容要点**:每卡 1 个痛点 + 2~3 行说明;痛点要真痛(bp-roadshow-guide:从市场端倒推,不是伪痛)。
- **动效**:卡片组 R1 错峰;核心痛点卡 R5 幕布揭示。
- **配图**:每卡场景图 1 张(3~4 张,同风格同色调)。

### T4 市场/数据
- **骨架**:左 45% 数据区(大数字 CAGR/规模 + 逐年增长柱状图,纯 CSS/SVG 画,不生图)→ 右侧 2×2 应用场景图阵 + 竖向标签 → 底部一句结论。
- **内容要点**:大数字先行;每个数字标来源;柱状图数据必须来自资料。
- **动效**:R4 数字滚动(大数字);柱状图条 R5 自下而上或 GSAP scaleY 逐根生长;图阵 R1。
- **配图**:场景图 4 张(2×2 同规格)。

### T5 解决方案/流程
- **骨架**:横向 3~4 步骤链条(图 + 斜角标题条 + KPI 胶囊),箭头串联;底部一句价值总结。
- **内容要点**:链条 = 「输入→处理→输出」的完整闭环;每步一个可量化收益(有出处)。
- **动效**:步骤卡 R1 错峰 + 箭头 P2 SVG 描边自绘(讲到哪步描到哪);结论句 R9。
- **配图**:每步场景/示意图 1 张。

### T6 核心技术/路线
- **骨架**:左 65% 三个圆形节点横向连接(采集→处理→应用类三级链路,圆环包图)→ 右侧倾斜摆放证书/专利卡 → 底部圆角说明卡(两条量化优势)。
- **内容要点**:技术链一环扣一环;证书/专利必须真实(比赛按专利号查重)。
- **动效**:节点间连线 P2 描边;节点图 R5 中心展开;优势卡 R1。
- **配图**:节点内圆形场景图 3 张;证书用真实扫描件(用户提供),没有就不放,**不生图伪造证书**。

### T7 权威背书/验证
- **骨架**:顶部一句大标题(委托权威机构检测/验证)→ 左「样品检测」场景照 + 中「检测报告」证书区 + 右竖排 3 个指标卡(大数字)→ 底部超大结论句。
- **内容要点**:第三方背书逻辑——自己说好不够,检测机构说好才可信;指标数字=报告原文。
- **动效**:指标卡 R4 数字滚动;结论句 R9 逐字点亮。
- **配图**:检测/实验场景照 1 张;证书用真实件。

### T8 教育/育人维度
- **骨架**:副标题一行 → 2×4(或 2×3)照片墙(统一圆角+细描边,弧形装饰线包围)→ 底部 3 个大数字指标。
- **内容要点**:创新大赛「个人成长 30 分」的承载页——科研育人、实践教学、跨学科融合;照片要本人出镜真实场景(bp-roadshow-guide 真实性红线)。
- **动效**:照片墙 R1 错峰(延迟短,8 张别拖太久);大数字 R4。
- **配图**:优先用户提供的真实活动照片;缺位才生图(场景示意,标注为示意)。

### T9 社会价值/就业
- **骨架**:上半「直接」纵向标签 + 横向三阶段时间轴(初期→3年→5年,人数递增)+ 末端场景图;下半「间接」纵向标签 + 超大带动数字 + 6 个产业链胶囊标签;底部透视地台。
- **内容要点**:人社赛事尤其看重;数字测算要有依据(带动系数写清口径)。
- **动效**:时间轴 P2 描边生长;大数字 R4;胶囊 R1。
- **配图**:末端场景图 1 张 + 左下场景图 1 张。

### T10 发展规划/路线图
- **骨架**:三栏递进模块(标题块 + 3~4 行规划 + 场景图,第三栏用强调色收口为终极目标)→ 底部向右上倾斜的成长时间轴(年份节点)→ 末端定位/地图图形。
- **内容要点**:「品牌→产品矩阵→国际化」式三级跳;每阶段有可检验的里程碑,不写空话。
- **动效**:时间轴 P2 描边向右上生长;三栏 R1;终点图形 R5 中心展开。
- **配图**:每栏场景图 1 张(3 张,递进感:实验室→产线→国际)。

## 通用模式补充页型

### G1 目录页
- **骨架**:左侧大序号 + 章节名纵向列表(不对称留白),右侧装饰图形或 IP。
- **动效**:列表 R1 错峰;序号 R9 逐字点亮可选。
- **配图**:可不要。

### G2 纯标题章节页
- **骨架**:超大章节序号 + 标题居中偏左,大面积留白,底部地台。
- **动效**:P1 逐字扰动或 R2 逐行揭示,一次就好。
- **配图**:可不要;要氛围可用一张大面积低饱和背景图。

### G3 结尾页
- **骨架**:致谢/口号大字 + 联系方式条 + IP 收口,与封面呼应(同构图镜像)。
- **动效**:R9 逐字点亮(口号);其余静态。
- **配图**:复用封面 IP。

## 动效使用上限(每页自查)

- 一页最多**两处**入场编排(配方计次,静态装饰不计);
- 单个动效 ≤1.2s;全页入场总时长 ≤2.5s;
- 完工态写常规 CSS,动效从完工态倒播;
- 答辩利器:R8 点击逐条叠加可突破「一次性」限制(讲到哪出哪),但一页只用于一个序列。
