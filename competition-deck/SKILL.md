# competition-deck — 类 PPT 网页

把主题和资料变成一套 16:9 固定翻页式网页:视觉上像高水平竞赛 PPT,载体是单个 HTML 文件,带真实动效与真实配图。

## 两个模式

| 信号 | 模式 | 差异 |
|---|---|---|
| 「比赛/参赛/路演/答辩/创新创业/技能大赛/挑战杯/三创赛」 | **比赛模式**(默认) | 内容规划必读 bp-roadshow-guide;页型从 `references/page-types.md` 目录选型;真实性红线从严 |
| 只给主题和资料,无比赛语境 | **通用模式** | 跳过评分方法论,直接按资料规划页面;页型目录同样可用,但允许自由页型 |

## 工作流(五阶段,顺序不可乱)

**阶段 1 · 内容规划(先规划,确认后才动工)**
- 比赛模式:先读全局 skill `bp-roadshow-guide`(按其「使用方式」按需读 references,不要一次全读),用「问题 → 方案 → 数据 → 价值」四步法校准叙事主线。
- 产出**页面清单**给用户确认,表格形式:页码 | 页型 | 标题 | 核心内容(2~3 行) | 关键数据 | 配图需求。
- 页数纪律:比赛路演 8~15 页;通用模式按资料量,宁精勿滥。
- **用户确认页面清单前,不写任何 HTML。**

**阶段 2 · 视觉母版**
- 按 `references/visual-tokens.md` 选定主色 token(默认医疗绿,可按项目气质换预设色板或自定义 hex)+ 字号阶梯 + 页眉/地台规范。
- 一页纸给用户确认(色板 hex + 一页结构示意),确认后锁定,全套页面不得漂移。

**阶段 3 · 建壳**
- 按 `references/deck-shell.md` 建 `decks/<项目名>/index.html`:16:9 壳、翻页控制、页码、空 slide 骨架。
- 从 `assets/lesson/libs/` 复制 `gsap/`(及用到的插件)进 `decks/<项目名>/libs/`,相对路径引用——deck 目录必须能整个打包带走、断网可用。

**阶段 4 · 逐页制作**
- 每页:`page-types.md` 选骨架 → 填真实内容 → 按映射表挂动效 → 需要配图时走 `references/image-pipeline.md`(Codex CLI 生图)。
- 相邻页骨架不得重复;一页最多两处入场编排。
- 每完成 2~3 页给用户过目一次,不要十页做完才亮出来。

**阶段 5 · 验收**
- playwright 逐页截图 1920×1080(范式见 deck-shell.md §验收),逐页人工过目 + console 零报错。
- 翻页瞬时性:快速连翻 10 页无卡顿、无动画中途态残留;`#页码` 直达可用。
- 数字复核:页面上每个数字都能在用户给的资料里找到出处;找不到的删或改。

## 红线(违反即返工)

1. **生图只产元素,不产页面**:人物/场景/IP/装饰图形走 Codex CLI;**一切文字、数据、图表必须 HTML 原生渲染**。评委要看清小字,且数字必须可改可查——烧进图片里就死了。
2. **翻页瞬时可达**:单个入场动效 ≤1.2s;翻页/跳页直接到位,动画可跳过。评委说「翻到第 7 页」时任何动画都不许挡路。
3. **不编造数字**(比赛模式尤其):真实性是比赛一票否决红线。资料里没有的数据,标「待补」占位并告知用户,绝不虚构。
4. **产出位置**:`decks/<项目名>/`,已 gitignore,不入库。图片放 `decks/<项目名>/assets/`,相对引用。

## 设计纪律(浅色母版下的反 AI 味)

继承 hallmark 与课件约定第 3 条,适配浅色底:
- 单主色调 + 一个强调色(橙系),主色+白底占页面 80% 以上;禁紫蓝渐变背景、渐变标题字、emoji 当图标。
- 结构按内容选型(流程→横向链条、对比→左右分栏、数据→大数字、清单→不对称网格),不许每页都是「居中标题+四列等宽卡片」。
- 中文只用系统字体栈("Microsoft YaHei","PingFang SC",system-ui),靠字重字号分层。
- 动效只动 transform/opacity/clip-path,ease-out 类缓动;完工态写常规 CSS,动效是「从完工态倒播进来」,JS 失效页面照样成立。

## 动效配方(复用 ENGINEER_PROMPT 编号,不新建)

配方全文唯一权威源 = `electron/agent/pagegen-prompt.ts`,本 skill 只做页型→配方映射(page-types.md)。**注意形态差异**:翻页式无页面滚动,scroll 驱动的配方(R0、P3 scrub、P5 Lenis)不适用;scroll/click 触发统一改为「slideenter 事件触发」,接线见 deck-shell.md §动效接线。

常用映射速查:R1 错峰入场(卡片组/清单)、R2 逐行揭示(短标题)、R4 数字滚动(数据页大数字)、R5 幕布揭示(图片/对比栏)、R9 逐字点亮(结论句)、R8 点击逐条(答辩讲到哪出哪)、P1 逐字扰动(封面/终页标题)、P2 SVG 描边(流程线/路线图)。
