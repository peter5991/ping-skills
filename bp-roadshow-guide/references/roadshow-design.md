# 路演设计指南

覆盖:路演认知 → 赛前准备 → 现场分析 → 内容设计 → 开场结尾 → 路演稿 → 台风 → 选人与 AB 角 → 实战练兵。文末附自检清单。

## 1. 路演认知

- 时长基准:校赛 5-6 分钟,省赛按 10 分钟备赛对标国赛;退役军人赛"1+8+5+1"(1 分钟视频+8 分钟路演+5 分钟提问+1 分钟打分)。
- **完美演示三组成**:内容(载体最关键,另有实物 demo、30 秒短片)、形式(传统规范式/接力式/小品式/相声式)、过程(变数最多——背稿宕机、黑屏死机都要做临场预案)。载体完美只完成约 45%,路演演砸照样丢分。
- **成功公式**:好的策划 + 好的载体 + 好的讲稿 + 反复预演(标杆:跨年演讲提前半年到一年准备;雷军每页讲什么用什么图都提前预演)。
- **左脑右脑**:左脑管内容逻辑、右脑管视觉呈现,两边都要调动。批评两种风气:"吹牛大赛"(包装过度)与"PPT 选美"(每页超 300 字、密密麻麻让评委恼火)。

## 2. 赛前准备:三原则、四大准备、三大清单

- **三原则**:三重目标(吸引、关注、说服);路演远比你想象的重要;准备、准备、再准备。
- **四大准备**:①设定目标三层级——传递信息、说服接受、激发行动;②听众分析——讲听众想听的,不是讲你想讲的;③头脑风暴梳理素材;④结构设计。
- **三大准备清单**:
  1. **分析清单**:分析听众(评委类型与关注点)、设定目标(好演讲要带来下一次 action);
  2. **内容清单**:选素材(确定讲与不讲,按赛事打法取舍)、搭结构(总分或总分总;红旅公益组/创意组/创业组结构各异)、插细节(哪页加案例、哪页加视频、哪页做转折——像导演设计演唱会环节)、串讲稿;
  3. **演示清单**:先整理图片库、明确每张图的用意再做页面;画演示流程图(哪里抛案例、转折、加视频);再制作页面。

## 3. 现场分析:4W 与锚定效应

- **When**:时长多少、有无提问、有无 demo 环节。
- **Where**:容纳人数、设施设备、屏幕 4:3 还是 16:9(反面案例:酒店宽屏把 16:9 拉变形,主办方没提前公告,选手现场改资料)。
- **What**:目标链——过网评→进线下→省金资格→入围国赛;也有项目把比赛当产品发布会求曝光。
- **Who**:评委构成——投资人张口就问股权结构;企业级评委看创意能否走向创业;教育类评委关注育人。路演前必须搞清楚"给谁讲"。
- **锚定效应**:同组同类项目,先讲且出色者占优,抽签顺序要留意;防主持人报错赛制,提前核实。

## 4. 8 分钟黄金分配与内容四步法

- **时间分配**:0-45 秒开场(不超过 1 分钟) → 约 1-2 分钟问题引入 → 解决方案(最核心,留足时间) → 价值呈现(商业模式、落地案例) → 团队与成长 → 收尾。不是雨露均沾:媒体报道、企业荣誉 1-2 秒带过;商业模式要花点时间讲清。
- **常见毛病**:"这是我们的商业模式、这是我们的营销策略"一句话带过,把时间全堆在技术方案上。
- **内容四步法**:问题、方案、数据、价值。**评委核心四问**:痛点真不真?方案行不行?数据硬不硬?团队强不强?
- **语言转化**:路演语言要体现评审规则关键词——工匠精神、产教融合、真实改变;近年导向更多关注人(调研的人、实施的人、人的获得)。

## 5. 五大核心法则

1. **痛点**:泛不如准、准不如痛——把痛说透。
2. **技术**:术语变比喻、原理变动作——"讲人话"(范本:"货车帮=货车里的滴滴打车")。
3. **价值**:把参数翻译成收益——不说"精度 0.01 毫米",说"不合格率从每万件 50 降到多少、五年省 200 万"。
4. **战略**:项目连国家、小我连大我。
5. **数据**:观点变事实、事实变证据。

## 6. 亮点提炼五招

1. **国家助力**:"独家授权""××总站唯一指定"——权威感拉满。
2. **竞品凸显**:"性能领先竞争对手,价格仅为对手 50%"。
3. **核心技术阐明**:"三大技术:第一率先突破……第二通过……实现……第三拓展……"。
4. **专利技术**:"核心发明专利多少项、在申请多少项,保证护城河"——要分清是不是真壁垒。
5. **获奖放大**:"中关村高新技术企业""亚太××一等奖"。

## 7. 开场 Magic Seven 与结尾 Magic Five

**七种开场法**(可单用或嵌套;当前最常态为直击痛点法、问题法、类比法):

1. **问题法**:"各位老师,你们抑郁吗?"——直给有冲击力。
2. **事实陈述法**:数据现象开场("今年新生儿出生率下降到 5‰——我们今天带来的项目是……")。
3. **回顾前瞻法**:"过去你们用这种,今天有更好的选择"。
4. **故事法**:好用但已套路化(破绽:"20 年前我就有新媒体梦想");用 SCQA 框架(情景—冲突—疑问—答案)组织。
5. **引言法**:找关联铺垫("今天报纸提到贵公司即将导入 ERP……")。
6. **格言法**:名言名句、诗导入。
7. **类比法**:两个不相干事物放一起说晦涩内容("我从小在江边长大,喜欢看百舸争流——这一幕很像污水净化产业的现状")。

好开场等于成功 50%:一针见血描述客户痛点,自问"这个问题急需解决吗";开场不能占总时长太大比例。

**五种收尾法**:总结式;号召式("来吧,一起加入我们");证言/名言警句式;故事式;诗词名句式。收尾呼应封面主标副标的核心价值,讲金钱之外的情怀——社会价值、生态价值、产业价值。常见问题:前后矛盾、时间不够仓促收场。提问环节是省赛最头疼的,赛前必须组织模拟提问集训。

## 8. 路演稿三版本与写改背化

- **三个版本**:1.0 逐字稿 → 2.0 提纲稿 → 3.0 关键词卡,按团队水平确定能到哪一级(反面:约 2/3 选手拿二十几页厚稿上台念)。
- **字数参考**(按个人语速调整):5 分钟≈1200 字、6 分钟≈1400 字、8 分钟≈1600 字。稿上标注时间分配(开场 55 秒、解决方案 1 分 35 秒),按 5/6/8/10 分钟不同时长切分。
- **四步打磨**:写 → 改(砍废话、补数据、调结构、加修辞) → 背 → 化(内化)。重点项目页面定稿后再定逐字稿,揣摩金句。
- **逐字稿四大作用与指导老师四角色**:拉起评分(对照评审规则逐条打勾——**质检员**);找佐证(论证论据齐备——**证据链审查员**);个性化(有没有自己的场景和故事感——**创意顾问**);书面语变口头语(**教练**)。

## 9. 台风训练:55/38/7 法则

信息传递中**视觉占 55%、声音占 38%、文字内容只占 7%**——体态态度比语言更重要。

- **躯干**:站直不驼背、站稳不摇晃;紧张时翻页笔乱点会暴露紧张。
- **眼神**:看观众三角区或画"Z"字扫视,不死盯一人。
- **面部表情**:自然亲和;常见问题是只有一个表情、声音一浪高过一浪。
- **手势**:五种常见姿态;训练靠一对一对应练习+团队拍视频抠细节(必须看自己的录像)。
- **语言**:吐字清楚、适当停顿;戒"然后""那么""就是";国赛评委全是省外专家,必须用普通话。
- **声音四要素**:音量、语调、语速、停顿。练法:换重音反复练、绕口令、读报纸模仿新闻联播。技巧:突然的轻声比高音更抓注意力。
- **步伐**:"定海神针"——站稳为主,可前后小幅移动,不左右乱摆。
- **形象**:校服或定制服装、整洁;细节穿帮(丝袜破洞)直接干扰评委视线。
- **紧张对策**:适度紧张是必要的。预防六条:良好休息、半饱状态、提前到场、准备再准备、熟悉会场、熟悉内容。消除小方法:握臂-放松、深呼吸、上台前冥想。

## 10. 路演人选:按赛道选人,一律 AB 角

- **最理想是项目负责人自己讲**——只有自己讲自己的故事才感人;但"既能讲又能做"的人极少,要想别的办法。
- **大批量选人**:发动学生写简历,选特殊身份经历的人(退役军人、技能大赛金奖、特殊地域);穿工装戴安全帽到厂里拍,讲自己的故事。**选人一律双份**,怕中途不干。
- **赛道与人的匹配**:职教、红旅赛道不能选模特式路演人;农业项目要一看就是真在农村干过的人(评委会追问雅安常年温度紫外线);残疾学生带乡亲致富上台只讲自己的故事就能拿高分。
- **空乘选人法**:把项目材料发给所有学生自悟,一周后上台讲,5 分钟能讲完不怯场即过关,再有目的地拉进团队。
- **AB 角机制**:必须设 AB 角防生病顶不上;标杆案例:两名女生从身体僵硬练起,每天练微笑练自然,练了八个月成型。可先内部竞争,实在不行两队合并重组——鸡蛋不放一个篮子里。
- **反面案例**:一个学生同赛道同赛场路演两个项目,换套衣服继续上——评委当场戳穿。

## 11. 以战养战:省赛空窗期的练兵策略

- 不能 5 月报名就等到 9-10 月打省赛:期间有任何比赛都去报,让团队被各比赛"鞭打",回来复盘"评委为什么戳穿我、下次怎么答"。
- 不同赛事风格不同:教育系统提问委婉;"创客中国"资格审查当场质疑真假、要求出示专利——经历过就游刃有余。
- 临场应变的价值:专科生同台博士,按套路介绍必垫底,临场改为只讲"我们是退役军人团队,把退役费砸进了项目",最终拿银奖——这就是降维打击:各种比赛练多了,视野经历超过同龄人,评委可能还重合。

## 路演自检清单(上场前逐项过)

**内容**
- [ ] 开场≤1 分钟且一针见血戳中痛点,通过"急需解决吗"自问
- [ ] 四步法齐全(问题→方案→数据→价值),评委四问都有答案
- [ ] 时间分配向解决方案倾斜,商业模式讲清了,荣誉媒体报道只 1-2 秒
- [ ] 术语已变比喻、参数已翻译成收益
- [ ] 亮点五招至少用上两招;语言含评审规则关键词
- [ ] 收尾呼应封面,讲了金钱之外的情怀

**稿子**
- [ ] 路演稿到 2.0 提纲稿以上;字数与时长匹配(1200/1400/1600)
- [ ] 稿上标注了每段时间分配
- [ ] 对照评审规则逐条打过勾;佐证齐备;书面语已变口头语

**现场**
- [ ] 4W 已核实(时长/场地/屏幕比例/评委构成)
- [ ] 提问环节做过模拟集训;抽签顺序与锚定效应已考虑
- [ ] 黑屏死机、设备故障有临场预案;材料有备份

**人**
- [ ] 路演人与赛道匹配,是"真做过"的人
- [ ] AB 角到位且都演练过
- [ ] 台风过过录像抠细节;紧张对策各人已选定
