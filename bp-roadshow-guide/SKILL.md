# BP 撰写与路演设计指导手册

本 skill 蒸馏自 2026 年 9 月"双创国培"(安徽省职业院校双创大赛指导教师国培班,7 天)全部与商业计划书撰写、网评材料、路演设计相关的培训内容(内部培训整合文档未随仓库发布)。

## 使用方式

接到 BP/路演相关请求时,按以下流程工作:

1. **判断场景**:写新 BP / 诊断修改已有 BP / 网评材料体系 / 路演内容设计 / 路演稿与台风 / 路演载体(PPT 或网页)。
2. **按需读取对应 reference**(不要一次全读):
   - BP 撰写、诊断、逐模块修改 → `references/bp-writing.md`
   - 路演内容、开场结尾、路演稿、台风、选人 → `references/roadshow-design.md`
   - 载体选择与制作规范(PPT / 网页演示页)→ `references/presentation-mediums.md`
3. **输出方式**:诊断按"模块逐项:问题 → 标准 → 修改动作"反馈;新建指导按"结构 → 每部分写什么/怎么写/常见错误"给方案;收尾给对应自检清单。

## 第一性原理:一切材料为评审服务

写任何内容之前,先用这五条校准方向:

1. **30 秒定生死**:评委先看题目有没有意义,再看目录、格式、页码,"一拖大概就知道分数"。材料的第一眼信息密度决定生死。
2. **网评定生死**:比赛只有网评和现场两环节,网评被干掉连说的机会都没有。评委看材料的真实顺序是:**1 分半视频 → PPT → (基本不看)计划书 → 附件**。投入顺序必须与此一致。
3. **评分四维**:个人成长 30 / 项目创新 30 / 产业价值 25 / 团队协作 15(职教赛道权重;挑战杯按科学性、先进性、现实性年度调配)。立德树人(价值观导向)排第一位。
4. **各赛事侧重不同,在不同的坡唱不同的歌**:创新大赛看个人成长与育人;创客中国看技术含金量(资格审查极严);挑战杯大挑重科研、小挑重落地;人社赛事看带动就业;投资人看盈利;红旅公益组看高度+温度+背书。评委构成(教育类/企业类/投资类)决定话术。
5. **真实性是一票否决的红线**:AI 查重(与往届资料重合率超 30% 即危险)、按专利号查重、查指导老师重复率、AI 检测造假文字并已通报学校。调研照片要本人出镜、带地理时间信息;财务要"四流合一"(合同、发票、银行回单、纳税)。2026 新规:学籍锁定、国赛获奖项目终身禁赛、一人一赛道一项目、教师不得代替学生完成核心内容、团队贡献度必须写实。

## 方法论地图

```
选题(决定天花板) → BP 撰写(17 模块) → 网评材料(视频→PPT→计划书→附件) → 路演设计(内容→稿→人) 
```

**选题阶段先回答的问题**(详见 bp-writing.md 第 0 节):
- 赛道数据测算了没有?(报录比、死亡之组、凑组现象——翻本省近两年各赛道报名量与获奖数据再报名)
- 项目来源是否属于六大高命中渠道:学生/毕业生自发、科技成果转化、特色专业优势学科、创二代家族企业、校企合作真实痛点、课堂孵化?
- 痛点是真痛还是伪痛?(从市场端倒推:先找最大需求客户,问愿付多少钱,再评估做不做得出)
- 职业院校获奖画像:科技创新类(非卡脖子)、工匠精神类;小切口单品突破;不做平台型、不做纯商业模式创新。

**BP 一句话主线**:你是谁 → 发现了什么真实问题 → 证据在哪里(证据链) → 怎么解决 → 相比现有方案优势在哪 → 个人成长。

**路演一句话主线**(内容四步法):问题 → 方案 → 数据 → 价值;对应评委四问:痛点真不真?方案行不行?数据硬不硬?团队强不强?

## 关键数字速查

| 场景 | 数字 |
|---|---|
| 路演时长 | 校赛 5-6 分钟、省赛/国赛按 10 分钟备赛;退役军人赛 1+8+5+1 |
| 路演稿字数 | 5 分钟≈1200 字、6 分钟≈1400 字、8 分钟≈1600 字 |
| 8 分钟分配 | 开场≤1 分钟 → 问题 1-2 分钟 → 方案(留足) → 价值 → 团队成长 → 收尾 |
| 网评 PPT | ≥50 页才能展示充分;挑战杯等另有正文页数硬限(以当年通知为准),厚度靠"正文+附件支撑材料" |
| word 计划书 | 100-300 页(视附件而定) |
| 台风法则 | 视觉 55% / 声音 38% / 文字 7% |
| 财务控制线 | 现金流缓冲 6-12 个月;资产负债率≤50%;流动比率约 2 |
| 估值参考 | 传统制造业约上年产值 5-6 倍、互联网 10-20 倍 |
| 产值验证 | 零申报企业季度<90 万、年产值<360 万(评委验产值逻辑) |
| 问卷类项目 | 样本量 3000+ 较稳妥、调研方法≥4 种 |
| 中试成本 | 硅胶模约 3000 元(50 个验证)、钢模最小约 10 万(量产) |

## 边界声明

- 本 skill 的方法论、案例、数字均来自培训授课口径;标注"以官方为准"的政策细节(时间节点、名额、奖金、税收)使用前必须核实当年官方文件。
- 路演网页(HTML 演示页替代 PPT 做主陈述)部分是基于路演通用原则的载体延伸推导,非培训原生内容,在 `references/presentation-mediums.md` 中单独标注。
- 涉及具体项目时,先问清:赛事名称与赛道组别、项目阶段(创意/初创/成长)、学生还是教师主导、已有素材(专利/合同/数据)。不同赛道组别,BP 写法和结构不同。
